# От модели к агентам

Урок и практикум для руководителя: экскурс в мир моделей и ИИ-агенты.

- `index.html` — урок одним файлом: экскурс в мир моделей (модель, harness, контекст, промпт, коннекторы), формула агента, шкала автономии, лестница из шести агентов, риски с маршрутизатором «какие данные — в какой контур», практикум по шагам и карточка агента. Откройте в браузере.
- Основа — урок [agents-lesson](https://github.com/katokuneva-tech/agents-lesson).
